# 投放利润看板

本地优先的电商投放利润台账：把聚水潭导出的商品销售数据、付费投放金额和每次调整动作放在一起看，直接算出每个链接的利润、ROI 和调整是否有效。

数据全部留在本机（`localStorage` / `chrome.storage.local`），可选通过坚果云 WebDAV 在多台设备间同步，不经过任何中间服务器。

## 功能

- **利润表**：导入聚水潭导出的销售明细，按店铺 / 链接 / 日期汇总销售额、成本、推广费，算出毛利与投产比。
- **付费调整记录**：每次调价、调预算、改出价都记一笔（改动前 / 改动后 / 为什么改 / 后续计划），事后可回看这条调整到底有没有用。
- **调整计划**：还没动手时先把方案存成待办，不占调整记录、不带时间；真正改完点「✅ 已调整」，按确认时刻生成一条正常记录。
- **一键抓取**：扩展版在聚水潭页面里直连报表接口，选店铺 + 时间就能拉数据，不用手动导出再导入。
- **导出**：调整记录可导出 JSON 备份，调整计划可一键导出 Excel（10 列，带表头样式、冻结、筛选）。

## 两种使用方式

| 方式 | 说明 |
| --- | --- |
| 单文件版 `index.html` | 双击即用，功能完整，数据存在浏览器 `localStorage` |
| Chrome 扩展 `extension/` | 额外支持聚水潭一键抓取、下载监听、云同步 |

安装步骤见 [插件安装说明.md](插件安装说明.md)：`chrome://extensions/` → 开发者模式 → 加载已解压的扩展程序 → 选择 `extension` 目录。

## 目录

```
投放利润看板/
├─ index.html          ← 唯一源码（单文件版），改逻辑只改这里
├─ build/
│  ├─ build.js         ← 从 index.html 拆出 extension/（node build/build.js）
│  └─ icons.js         ← 生成扩展图标（node build/icons.js）
└─ extension/          ← 构建产物，Chrome 直接加载这个目录
   ├─ manifest.json
   ├─ app.html / app.js / store.js / sync.js
   ├─ import.js        ← 聚水潭导出文件的读取（扩展版）
   ├─ jst.js           ← 在聚水潭页面内调用报表接口（扩展版）
   └─ bg.js            ← 后台：云同步、下载监听、一键抓取编排
```

改完 `index.html` 要跑一次 `node build/build.js` 重新生成 `extension/`，否则扩展里还是旧代码。`manifest.json` 的版本号由构建脚本跟随页面上的版本徽章自动写入。
